# Gainz-for-XBox

Finds indie Steam games that share the statistical DNA of recent breakout hits
(R.E.P.O., PEAK, Raft, Silksong, etc.) but haven't broken out commercially yet
and aren't already on Xbox Game Pass — candidates worth Xbox investing in /
adding, and titles Game Pass subscribers almost certainly don't already own.

Everything is reproducible from `data/raw` using the scripts in `src/`, run in
the order below. `data/` is gitignored (raw data is large / not ours to
redistribute), so cloning this repo means re-running the pipeline to
regenerate `data/processed/`.

## Data

- `data/raw/super raw/` — a Steam snapshot (~Dec 2024) from SteamSpy + Steam
  reviews: `games.csv`, `genres.csv`, `tags.csv`, `categories.csv`,
  `steamspy_insights.csv`, `reviews.csv`. ~140,000 apps.
- `data/reference/web_indie_2025_2026.csv` — hand-curated, **not regenerable**.
  30 Steam indie breakouts from 2025-2026 (newer than the raw snapshot),
  researched from gaming press, one source URL per row. Losing this file loses
  the research behind it.
- `data/processed/` — everything else here is generated by a script in `src/`;
  see the pipeline table below for which script makes what.

**Known raw-data gotcha:** `games.csv`'s `price_overview` column embeds JSON
using backslash-escaped quotes (`\"`), not standard doubled CSV quotes. Reading
it with plain `csv.DictReader` silently misaligns the `name`/`type` columns on
~13% of rows and drops well-known indie hits from the "game" type filter. Any
script reading `games.csv` must use `csv.DictReader(f, escapechar="\\")`.

## Pipeline (run in this order)

| # | Script | Reads | Writes |
|---|---|---|---|
| 1 | `src/extract_owners_price.py` | `data/raw/super raw/steamspy_insights.csv` | `data/processed/owners_price_buckets.csv` |
| 2 | `src/extract_reviews.py` | `data/raw/super raw/reviews.csv` | `data/processed/review_amount_buckets.csv` |
| 3 | `src/pipeline.py` (also runs 1 & 2 itself) | all of the above + `genres.csv`/`tags.csv` directly | `data/processed/pipeline_dataset.csv` — one row per app: `app_id, genres, tags, price_cents, review_score, total, owners_range` |
| 4 | `src/build_top50_datasheet.py` | `games.csv`, `genres.csv`, `tags.csv`, steps 1-2's outputs, `data/reference/web_indie_2025_2026.csv` | `top50_indie_reference.csv`, `top50_match_profile.csv`, `indie_candidates_scored.csv` |
| 5 | `src/find_underdogs.py` | `indie_candidates_scored.csv` | `underdog_candidates.csv` |

```
python src/pipeline.py
python src/build_top50_datasheet.py
python src/find_underdogs.py
```

## Step 4 — `build_top50_datasheet.py`: what makes a winner

Blends two evidence sources into one blended top 50
(`top50_indie_reference.csv`):

- **Web side (30 rows):** researched 2025-2026 Steam indie breakouts, too new
  for the Dec-2024 snapshot to have caught.
- **Dataset side (20 rows):** the top 20 apps in the raw snapshot itself,
  ranked by a composite performance score —
  `0.35·z(log owners) + 0.35·z(log reviews) + 0.30·z(review_score)` — among
  indie games with ≥5,000 reviews. A handful of non-indie/utility entries
  (Wallpaper Engine, Rocket League, etc.) are manually excluded with reasons
  documented in the script.

From that combined evidence, it builds a **"winning profile"**
(`top50_match_profile.csv`): a naive-Bayes lift table comparing a 300-game
"winner cohort" (indie, review_score ≥8, ≥20,000 reviews, ≥1,000,000 owners)
against the other 85,332 indie games in the snapshot, per tag / genre / price
band (min support: 5 winners and 50 total; Laplace smoothing 0.02 — 216
attributes survive).

Every indie game in the snapshot is then scored against that profile
(`indie_candidates_scored.csv`, 85,632 rows) with a full naive-Bayes
log-likelihood ratio — `profile_fit_score`, 0-100, where absent attributes
count too so a game isn't rewarded just for carrying more Steam tags. A
`priority_score` blends fit with observed performance; `evidence_tier` flags
how much review volume backs the number (`high` ≥5,000 reviews).

**Validation:** `profile_fit_score` separates the 300-game winner cohort from
the other 85,332 indie games with **AUC 0.939 in-sample, 0.950 on a held-out
30%** of the winner cohort (seed 7) — the profile generalises rather than
memorising.

**Headline findings** (both evidence sources agree):
- **Co-op is the strongest signal** — Co-op 5.5x lift, Online Co-Op 5.1x,
  Multiplayer 4.5x. Matches 2025's charts directly: R.E.P.O. (18.4M units),
  PEAK (15.7M), Schedule I (8.0M), 2026's Meccha Chameleon (15M copies in
  under a month) are all co-op.
- **Sandbox/systems depth** — Moddable 4.5x, Sandbox 4.1x, Open World 3.4x,
  Open World Survival Craft 3.4x, Building 2.9x, Crafting 2.5x.
- **Price:** $15-29.99 dominates catalogue winners (`$20-29.99` lift 5.8x);
  free and sub-$5 badly under-perform (0.40-0.41x). 2025-26 viral breakouts
  sit lower ($4.79-$19.99) — two distinct playbooks: durable catalogue value
  at $20-30 vs. viral volume at $5-10.
- **Negative signals:** Casual 0.52x, Early Access 0.68x, Stylized 0.31x,
  Combat 0.32x, 3D 0.47x, Minimalist 0.50x.

## Step 5 — `find_underdogs.py`: the "underdog" shortlist

The goal isn't just "games that match the profile" — the winner cohort itself
matches the profile perfectly and is already a hit. The goal is games that
match the winning DNA **but haven't broken out yet and aren't already
on Xbox Game Pass** — i.e. things Xbox could plausibly add that subscribers
don't already own.

Filters applied to `indie_candidates_scored.csv`:
- `in_winner_cohort == 0` — excludes games that already broke out (that's the
  definition of "not an underdog").
- `in_top50_reference == 0` — excludes the top-50 set itself.
- `evidence_tier == "high"` (≥5,000 reviews) — enough signal that the
  review score is trustworthy, not a fluke from a handful of ratings.
- `review_score >= 6` — excludes games that fit the profile's tags on paper
  but were actually poorly received.
- Ranked by `profile_fit_score` descending (the validated similarity metric
  from step 4).

**Xbox Game Pass availability isn't in any dataset here** — it's not
derivable from `data/raw`, so the leading candidates were checked individually
via web search (dated 2026-08-21) and recorded in the script as
`GAMEPASS_STATUS_OVERRIDES`, each with a source note. Anything confirmed
`on_gamepass` is kept visible in the output (not silently dropped) but
excluded from the final top-5 pick.

Output: `data/processed/underdog_candidates.csv` — the full filtered/ranked
pool (currently 1,034 games), not just the top 5, so the next-best options are
visible if a pick later turns out to already be on Game Pass.

All five are survival/crafting co-op games — matching the profile's strongest
signals (co-op, sandbox, open-world survival craft) — well-reviewed and
established (thousands of reviews, hundreds of thousands to ~2M owners) but
well below the winner cohort's scale (1M+ owners *and* 20,000+ reviews *and*
review_score 8+): proven enough to be a safe bet, obscure enough that
subscribers likely don't already own them.

**Notable exclusion:** Voidtrain (1159690) ranked 3rd by fit score but was
confirmed added to Xbox Game Pass day-one on 2025-11-07 — excluded from the
picks, kept visible in the CSV with `gamepass_status = on_gamepass`.
