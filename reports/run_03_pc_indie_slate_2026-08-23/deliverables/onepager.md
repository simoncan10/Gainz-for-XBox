**Removal rules by tier.** T1: remove on evidence of a prior Game Pass run (the title then owes
Tier 2's question first). T2: remove if Microsoft's own record puts the prior run in the bottom
quartile of engagement per licensing dollar among comparable back-catalogue titles, **or** if no
counterparty with clear signing authority is identified within **30 days**. T3: remove on either
branch of the status check (already included → nothing to buy; confirmed departed → moves to
T2), **plus** remove any title whose quote pushes the tier below **41.39 titles per $1,000** —
the non-indie benchmark the whole case rests on.
